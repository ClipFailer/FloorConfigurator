# FloorConfigurator

Тестовое задание для PlayEstate. UE 5.8, C++.

## Архитектура

Разделение по ответственности:

| Слой | Класс | Зачем |
|---|---|---|
| Данные | `FApartmentData`, `FFloorData`, `FBuildingConfig` | Чистые `USTRUCT` для хранения конфига |
| Парсинг | `FConfigLoader` | Статический класс, изолирует работу с JSON |
| Состояние | `UFloorConfiguratorSubsystem` | Источник истины: конфиг + текущий режим камеры |
| Камера | `AConfiguratorCameraRig` | Отдельный актор, плавные перелёты |
| UI | `U*Widget` | Только отображение и ввод |
| Сцена | `AApartmentActor` | 3D-представление квартиры, подсветка |

### Абоснование выбора

**`UFloorConfiguratorSubsystem` вместо хранения в GameMode.**
Подсистема живёт весь сеанс, не теряется при смене уровня и доступна из любого
места через `GetGameInstance()->GetSubsystem<...>()`. GameMode существует
только на сервере и пересоздаётся при загрузке карты — для хранения
загруженного конфига не подходит.

**`FConfigLoader` — статический класс, не `UObject`.**
Парсинг не требует рефлексии или GC. Отдельный класс держит JSON-логику
в изоляции: если завтра источник данных сменится (HTTP, БД), Subsystem
не изменится — поменяется только лоадер.

**`AConfiguratorCameraRig` — отдельный актор, не привязан к персонажу.**
В конфигураторе нет игрока в привычном смысле — есть «глаз», который
летает между точками интереса. Отдельный актор позволяет свободно
управлять позицией через `FMath::VInterpTo` в `Tick`, не борясь с
`CharacterMovementComponent`. Вся логика перелётов — в одном классе.

**UI общается только с Subsystem.**
Через делегаты (`OnFloorSelected`, `OnApartmentFocused`, `OnFilterChanged`).
UI не знает ни о камере, ни о JSON, ни о 3D-акторах. Это позволяет
тестировать слои независимо и не плодит жёсткие связи.

**Парсер устойчив к битым данным.**
Валидация каждой квартиры (ID, площадь, статус, focusPoint), удаление
невалидных элементов без падения. Все ошибки — через `UE_LOG` с уровнями
`Warning` / `Error`.

## Запуск

1. Открыть `FloorConfigurator.uproject` в UE 5.8.
2. Собрать C++ модуль.
3. Запустить PIE.
